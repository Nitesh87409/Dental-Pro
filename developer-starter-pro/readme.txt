A premium dark glassmorphic WordPress theme for dental clinics — with appointment booking, AI chatbot, bug reporting, and WooCommerce styling.

== Description ==

**DentalPro Elite** is a premium WordPress theme built specifically for dental clinics, dentists, orthodontists, and oral healthcare professionals. It combines a modern dark glassmorphic design with powerful built-in functionality — no page builder required.

### Features
* Premium dark glassmorphic UI design
* 4 pre-built Header styles & 3 Footer layout options
* Built-in Appointment Booking System (no extra plugins required)
* AI Chatbot with live booking capabilities (OpenAI-compatible)
* Bug Report / Problem Reporting widget
* 12 Homepage sections (Hero Slider, Services, Testimonials, Before & After, FAQ, etc.)
* 7 Custom Post Types (Doctors, Services, Testimonials, Appointments, Before & After, Locations, FAQs)
* 4 Custom Taxonomies for categorization
* WooCommerce CSS-level styling for online product sales
* Dark Mode toggle
* WP-Cron automated email and SMS reminders
* Fully responsive and translation ready

== Installation ==

1. Upload the `developer-starter-pro` folder to your `/wp-content/themes/` directory.
2. Activate the theme through the **Appearance > Themes** menu in WordPress.
3. Configure your clinic details, colors, and layout via the **DentalPro Settings** menu.
4. (Optional) Import the provided dummy data using the WordPress Importer under **Tools > Import**.

== Frequently Asked Questions ==

= Does it include a page builder? =
No. DentalPro Elite uses custom modular page templates to keep your site fast, lightweight, and completely bloat-free.

= How do I manage appointments? =
Navigate to **DentalPro Settings > Appointments Dashboard**. Here you can view, approve, cancel, and complete appointments. 

= Can I use WooCommerce? =
Yes. The theme includes CSS-level styling for WooCommerce grids, cart, checkout, and forms.

= How does the AI Chatbot work? =
Go to **DentalPro Settings > AI Chatbot**. Enable it, and enter any OpenAI-compatible API key (OpenAI, Groq, OpenRouter). The chatbot can answer clinic questions and book appointments directly for patients.
