== Description ==

DentalPro Elite is a premium WordPress theme built specifically for dental clinics, dentists, orthodontists, and oral healthcare professionals.

It ships with a full custom appointment booking system, patient portal, AI chatbot, treatment cost calculator, and structured JSON-LD SEO schemas — all built natively without requiring any paid plugins.

The design follows a dark glassmorphic aesthetic with teal accent glows, floating badge animations, and premium typography using Outfit and Inter fonts.

Features:
* Dark glassmorphic UI with ambient teal glow effects
* Swiper.js hero slider with video background support
* 4 header styles (solid, transparent, sticky, centred)
* 3 footer layouts
* Dark Mode toggle
* Custom Appointment Booking System (multi-step wizard + REST API)
* Patient Portal (custom user role, appointment history, medical notes)
* AI Chatbot (rule-based keyword matching + REST API)
* Treatment Cost Calculator (shortcode: [dental_calculator])
* Automated WP-Cron appointment reminder emails
* Custom HTML email templates
* JSON-LD structured data (Dentist, Physician, Service, FAQPage, BreadcrumbList)
* Custom Post Types: Doctors, Services, Testimonials, Appointments
* WooCommerce compatible
* Child theme support
* Translation ready
* RTL stylesheet
* Demo data included

== Installation ==

1. Upload the theme folder to /wp-content/themes/
2. Activate the theme from Appearance → Themes
3. Go to DentalPro Settings to configure clinic info, colors, and booking options
4. Import demo data from /demo-data/demo-data.xml via Tools → Import → WordPress

= Does this theme require any plugins? =
No required plugins. Optional: WooCommerce for e-commerce functionality.

= Is this theme translation ready? =
Yes. A .pot file is included in the /languages/ directory.

= Does this theme support child themes? =
Yes. A starter child theme is included in /child-theme/ folder.
